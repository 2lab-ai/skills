Why the harness matters

When you chose Claude Code, you also chose your conventions: slash commands, MCP servers, subagents, hooks, and CLAUDE.md rules. Changing model providers should not require rewiring your entire agent stack.

llmux proxies the Anthropic API locally. Every request routes through your daemon, which reads your model name, consults its ledger, and forwards to the appropriate backend. The result comes back as if it came from Anthropic—unchanged to your harness.

  • One Rust binary: daemon, TUI, login, updater, launcher
  • Multi-account quota-aware scheduling and cooldown parking
  • Stable Homebrew channel; optional preview releases
  • Native macOS Islands companion and KDE/Qt port

Request receipts and debugging

Routing is not magic. Every request produces a receipt: the original model name you asked for, the backend it resolved to, latency, token counts, and the raw response body.

The live TUI shows you all four legs of every call in real time. A built-in viewer displays raw request/response bodies. Copy as curl to replay or hand off to another tool.

Remote-first topology and Islands

The llmux daemon runs on one machine (your desktop, a cloud instance, or a shared box). Clients on any other machine can connect to it via --remote flag and per-machine API keys. One account, multiple machines, one routing decision point.

macOS gets a native Islands companion app. Set your accounts once, and every Claude Code instance on the network knows how to reach the daemon. KDE and Qt ports handle Linux and other platforms with the same clean separation.

  • Pure clients: zero shared secrets on client machines
  • Per-machine auth keys tied to hardware
  • Native UIs for macOS, KDE/Qt, and command-line dashboards
  • Multi-account Fable ceiling controls

Install, operate, and first steps

Get the stable binary from Homebrew:

$ brew install 2lab-ai/tap/llmux

Start the daemon and launch Claude Code in one command:

$ llmux run

Log in or import existing accounts:

$ llmux login
$ llmux import --account <email@example.com>

Open the live dashboard in your terminal:

$ llmux dashboard

Or use the foreground mode to watch requests in the TUI as Claude Code runs.

For preview releases and optional Islands install:

$ brew tap 2lab-ai/tap
$ brew install llmux@preview
$ brew install llmux-islands

Candor

Ownership: llmux is built and maintained by 2lab.ai. Your accounts and API keys stay under your control. One human uses their own credentials; no pooling, resale, or third-party token sharing.

Policy: Third-party flat-rate subscription tokens (e.g., shared Codex, OpenRouter flex) are policy-dependent and opt-in. You decide which backends to enable.

Affiliation: llmux is not affiliated with Anthropic, OpenAI, xAI, or OpenRouter. It is a routing proxy that implements their published APIs.
